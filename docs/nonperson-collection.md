# NON_PERSON 负样本采集规范

> 目的：为 `NON_PERSON(3)` 类采集训练素材。该类目前**训练样本数为 0**（见
> `docs/tuning-log.md`），导致"排除物品误检"的职责全压在 `PoseExtractor` 的关键点
> 质量门上，使该门槛被迫定得极严、连带滤掉夜间真人。

---

## 一、红线（决定这次采集成败的唯一一条）

**每一条素材都必须是"整段、逐帧确认没有真人"的片段。**

否则等于**训练模型把真人判成"非人"**——后果是漏报（老人跌倒了，系统认为"这不是人"），
比现在"车被当成人"严重得多。

具体要排除的"真人"包括：

- 画面主体的人
- 远处路过、只占几十像素的人影
- **镜面/玻璃/地面的倒影里的人**
- 车窗内、门缝里、货架后**露出局部肢体**的人

> 参照我们踩过的坑：一次交叉验证在难例集上"零误杀"，但端到端实测误杀 9/105 ——
> 原因是那几帧"人倒在车旁"恰好没被标注。**"没注意到有人"和"确认没有真人"是两回事。**

**自检方法**：采完后用播放器**从头到尾看一遍**，确认没有人在任何时刻出现。若某段中间
有人经过，**整段废弃**，不要裁剪使用（裁剪边界处的滑窗会混入）。

## 二、要采什么（按优先级）

按我们实测到的误检类型排序，标 ★ 的是**必须覆盖**的：

| 优先级 | 类别 | 说明 | 我们已有的实例 |
|---|---|---|---|
| ★★★ | 带车罩的停放电动车/摩托车 | pose 给出 17 个高置信关键点（均值 0.718，比真人还高）：红头盔像头、车罩像躯干、轮子像腿 | `person_falldown-4.mp4`（夜间） |
| ★★★ | 静态车辆（停车场） | 雪地/夜间低对比度下被误检为人 | `person_falldown-3.mp4` 积雪停车场 |
| ★★ | 室内家具（沙发/椅子/床） | 当年 `NON_PERSON` 想解决的原始问题 | `Home_01` video(10) 的深红沙发 |

| ★ | 镜面/玻璃反射 | README「已知限制」已记录 | 待补 |
| ★ | 植物/花盆/垃圾桶/纸箱 | 质量门 docstring 提到的咖啡机/椅子/植物 | 待补 |

**建议每类 2 段以上**（同一类只给一段，模型容易只记住那一台的纹理）。

## 三、技术要求

| 项 | 要求 | 理由 |
|---|---|---|
| 格式 | `.mp4` / `.avi`（H.264 优先） | 与现有素材一致，OpenCV 直接可读 |
| 分辨率 | **≥ 1280×720**，建议 1920×1080 | 夜间素材分辨率太低会再造一个"域"，训练与部署不一致 |
| 帧率 | 25–30 fps | 与现有素材一致（`WINDOW_SIZE=30` 对应约 1–1.2 秒） |
| 单段时长 | **≥ 60 秒**，建议 2–5 分钟 | 30 帧滑窗 + stride=3，短片段出不了几个窗口 |
| 机位 | **必须固定摄像头**（三脚架/支架/固定安装），俯视或斜俯视 | 与部署场景（走廊/客厅/门口）一致。**手持/平移镜头不可用**（见下方验收标准） |
| 光照 | **白天与夜间都要**，夜间优先 | 夜间才是当前误检最严重的场景 |
| 画面内 | **不得有真人**（见第一节红线） | — |
| 其他 | 尽量包含目标**长时间静止**的镜头 | 停放车辆/家具的误检是持续性的，静止镜头最有代表性 |

**总量目标**：**合计 60–120 分钟**素材。
按 `WINDOW_SIZE=30`、`stride=3` 估算，约能产出 **1000–3000 个 NON_PERSON 窗口**
（对比：现有 `SAFE` 约 19000 个窗口，这个量级不会导致类别失衡）。

> 注意：**不是越多越好，而是越"像人"越好**。一段普通的空走廊如果 pose 根本不误检，
> 它对 `NON_PERSON` 的训练贡献很小。所以第二节的优先级顺序比时长更重要。

## 三之二、两条补充要求（2026-10-15 实测后追加）

### 1. 必须固定机位，且要能量化验收

第一批素材里出现了**手持/平移**镜头（运动均值 7.6–23.5），而部署是固定机位。这会造成
域差异，且可能让模型学到一条**反向伤害**的捷径：

> 若素材普遍"无人 + 镜头在动"，模型可能学到「**画面整体在动 ⇒ 这是非人**」。
> 那么固定机位下真人在动时，反而可能被推向 NON_PERSON —— 等于把真人判成"非人"。

**验收标准**（可复现）：对每段算帧间灰度差均值（缩放到 320×180 后逐帧相减取均值）。

| 素材 | 运动均值（实测） | 判定 |
|---|---|---|
| 固定机位夜间停车棚 | **1.25 – 2.52** | ✅ 合格 |
| 手持拍摄（第一天素材） | **7.6 – 23.5** | ❌ 不合格 |

**采集时/交付前**：运动均值 **> 3** 的片段请重拍或标注为"手持"。

### 2. 必须同时采集"画面里有人"的素材，且比例不低于 1/3

只用"无人"素材训练，模型无法知道自己该**在什么条件下不说 NON_PERSON**，
容易退化成"看到某一类画面就判非人"。所以需要用**同机位、同光照、同场景**下
**有人正常活动**的片段作对照。

要求：

- **同一批采集里就要包含**，不要事后补（同机位/同时段/同光照才有对照意义）
- 画面里的人做**正常活动**即可（走动、坐着、骑车站立），**不需要跌倒**
- 建议比例：**有人 : 无人 ≥ 1 : 3**（即有人素材占总时长 1/3 以上）
- 这些片段标 `has_person = yes`，我构建数据集时会**排除它们**（不能进 NON_PERSON），
  但会用它们验证"训练后的模型不会把真人判成非人"

## 四、目录与命名规范

```
dataset/
└── nonperson_raw/                    # 原始素材，不入 git（.gitignore 已含 dataset/）
    ├── ebicycle_park/                #   类别目录（见下表）
    │   ├── ebicycle_park_day_01.mp4
    │   └── ebicycle_park_night_01.mp4
    ├── static_vehicle/
    ├── furniture_indoor/
    ├── poster_wall/
    ├── mirror_reflection/
    └── misc_object/
```

类别目录名（固定用这 6 个，别自创）：

| 目录名 | 对应第二节 |
|---|---|
| `ebicycle_park` | 带车罩的停放电动车/摩托车 |
| `static_vehicle` | 静态车辆（停车场） |
| `furniture_indoor` | 室内家具 |
| `poster_wall` | 墙面/海报/告示牌 |
| `mirror_reflection` | 镜面/玻璃反射 |
| `misc_object` | 植物/垃圾桶/纸箱等 |

文件命名：`<类别前缀>_<光照day|night>_<序号两位>.mp4`，例如：

```
ebicycle_park_night_01.mp4
static_vehicle_day_03.mp4
```

```csv
file,category,lighting,camera,has_person,no_person_verified,duration_s,resolution,fps,captured_at,motion_mean,note
```

| 列 | 说明 |
|---|---|
| `camera` | `fixed` 或 `handheld`。**`handheld` 的片段不作为主力** |
| `has_person` | `yes` 表示画面里有人（对照素材，构建数据集时会排除） |
| `no_person_verified` | 仅 `has_person = no` 时需要，必须手填 `yes`：表示你已**从头到尾看过**并确认无真人。`has_person = yes` 的填 `-` |
| `motion_mean` | 帧间灰度差均值（缩放到 320×180）。**> 3 视为手持**，请重拍 |
| `note` | 简述场景（机位、光照、目标类型），便于日后复现 |

## 六、我拿到素材后会做什么

1. **有效性检查**：对每段跑一遍 `PoseExtractor`，统计"pose 把人误检"的帧比例
   - 比例高 → 该素材对 `NON_PERSON` 训练有价值
   - 比例接近 0 → 只是普通空场景，价值低（可保留，但不计入第二节的优先级覆盖）
2. **红线复核**：我会对**疑似有人的帧**（检出目标较大或关键点置信度较高的帧）做人工目视复核，
   把确认有真人的片段剔出来交给你确认，避免污染训练集
3. **构建数据集**：整段无人的片段 → 滑窗 30 帧 → 全部标 `NON_PERSON(3)`，
   并在 `processed/` 产出对应的 meta 记录（替换现在那份与实际不符的 `nonperson_meta.json`）
4. **重训 + 三套评估**（缺一不可）：
   - 难例集：当前基线 正样本召回 81.0% / 负样本误报 1/9
   - Le2i 12 段回归：正常 7 段必须全 0% WARNING/DANGER，跌倒 5 段首次 DANGER 帧不应明显提前
   - 真实 6 段：`person_falldown-4` 的电动车应不再被稳定框成"人"
